# Approved enemy readability proposal

The user approved these existing-art comparisons on 24 November 2026, then requested
implementation with hitboxes and attack alignment checked.

- `approved-sizes.png`: current resident art at the proposed species proportions.
- `approved-ranks.png`: normal / durable Moss / elite Brute beside Warden.

The interactive proposal also included the other species, all four facings,
unchanged variant palettes and a greyscale comparison. These are approval
compositions, not runtime captures or newly generated artwork. The originals
remain in the established gameplay/attack source archives. Implemented sizing,
rank cues and geometry are documented in `docs/enemy-size-hierarchy.md`.

The crown in the original rank capture was subsequently rejected, along with a
painted item-crown alternative. The user selected the Moss Brute down-arrow
language: one bone down-chevron for durable variants, two crimson down-chevrons
and a live health bar for elites. These rank cues reuse the resident white texel;
no new runtime artwork is required.
