# Approved fixed crypt layout

The user approved `approved-proposal.png` on 24 November 2026 and authorized
implementation using the existing artwork. The reference was composed from the
resident atlas pixels, original ground pivots and the game's isometric projection.
No new artwork was generated. It is a layout approval image, not a gameplay capture.

Runtime placements are in `assets/arena/crypt-layout.json`; the three paving bands
are in `assets/arena/crypt-floor.json`. The user additionally requested corrected
gate/altar ground alignment and all four corners checked again. Those corrections
are part of the implementation, so their draw geometry differs modestly from this
initial composition. All source PNGs and texture page dimensions remain unchanged.

See `docs/arena-redesign-proposal.md` for the current design and verification.
